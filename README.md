# CV Repository

A one-page CV maintained using **Markdown → HTML → PDF**.

* `resume.md` — **CV template and primary source**
* `resume.html` — Layout, styling and A4 formatting
* `resume.pdf` — Final application-ready CV
* `resumeupdate1808.pdf` — **Updated resume preview**
* `README.md` — Repository documentation

To check the latest updated resume, open **[resumeupdate1508.pdf](resumeupdate1508.pdf)**.

The repository keeps the CV content, design and final PDF together for easy updates and version control through Git/GitHub.
